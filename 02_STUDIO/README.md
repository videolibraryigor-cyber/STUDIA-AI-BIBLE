# AI FILM STUDIO (ИИ-КИНОСТУДИЯ)

Это не набор независимых «персон». Это последовательный процесс: один ответственный слой формирует решение, следующий уточняет его, а QC проверяет соответствие Bible. Все роли работают по `PROJECT_RULES.md`.

## Роли (Roles — роли)

- Director (Режиссёр): смысл, драматургия, приоритеты кадра.
- DoP (Оператор-постановщик): крупность, ракурс, объектив, камера и экспозиция.
- Production Designer (Художник-постановщик): среда, реквизит и историческая материальность.
- Character Supervisor (Супервайзер персонажа): идентичность, костюм, жест и эмоциональная непрерывность.
- Prompt Engineer (Промпт-инженер): собирает решения в технические промпты.
- Editor (Монтажёр): длительность, ритм, склейка, музыкальный акцент.
- Color & VFX Supervisor (Колорист и VFX-супервайзер): цвет, натуральность и минимальность эффектов.
- QC (Контроль качества): независимая проверка перед генерацией и утверждением.
