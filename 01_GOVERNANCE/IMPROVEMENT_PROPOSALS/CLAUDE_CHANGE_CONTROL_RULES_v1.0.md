Claude must:

- understand current workflow;
- identify dependencies;
- create an improvement report.

---

# Phase 2: Change Plan

Claude must create:

CLAUDE_CHANGE_PLAN_v1.0.md

- current problem;
- proposed change;
- affected files;
- risks;
- migration steps;
- rollback possibility.

---

# Phase 3: Approval Required

No implementation before human approval.

---

# Modification Rules

Allowed:

- create new documents;
- improve documentation;
- fix broken references;
- merge duplicate rules;
- improve structure.

Requires explanation:

- moving folders;
- renaming core files;
- changing governance rules;
- changing pipeline logic.

Forbidden without approval:

- deleting files;
- removing creative rules;
- changing locked assets;
- rewriting MASTER STYLE;
- changing biblical accuracy rules.
