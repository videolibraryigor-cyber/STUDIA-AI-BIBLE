# PROMPT LIBRARY (Библиотека промптов)

Промпт хранится рядом с его назначением, но утверждается только вместе с Scene Package. Никакой prompt не считается каноническим, пока его `Status` не `APPROVED`.

## Категории

- `CHARACTERS` — референсные и характерные промпты.
- `LOCATIONS` — локации и среды.
- `SCENES` — общие правила конкретной сцены.
- `SHOTS` — один пакет на кадр, созданный из шаблона.
- `VIDEO` — видеоинструкции, отделённые от Image Prompt.
- `NEGATIVE` — общие риски; дополняются рисками конкретного кадра.
