## Overview

**MASTER_TIMELINE synchronizes every shot with the musical score.** It serves as:
- Master document for all production timing
- Reference for shot duration and pacing
- Music-to-visual mapping for synchronization
- Cue sheet for timing generation requests
- Archive of approved timing decisions

**Format:** Timeline from 0:00 to ~4:00 minutes (est. 240-300 seconds), showing:
- Timecode ranges (0:00-0:30, etc.)
- Dramatic beat (Act + Scene)
- Shot IDs and descriptions
- Music character/section (tempo, mood, instrumentation)
- Notes on synchronization logic

**Blueprint alignment:** This timeline is built to follow the film's core structure from [FILM_BLUEPRINT.md](../../FILM_BLUEPRINT.md), including Opening, Discovery, Flashbacks, Return to Present, and Ending.

## Timing Flexibility Notes

**Estimated Duration: 240 seconds (4:00)**

### If Music is Shorter (3:30-3:45)
- Reduce shot durations slightly across all scenes
- Keep relative proportions (Act II still ~25% of runtime, etc.)
- Prioritize emotional moments over establishing shots

### If Music is Longer (4:30-5:00)
- Add breathing room to shots
- Insert transition shots or lingering moments
- Allow music instrumental passages to play without cutting
- Add silence/pause moments for reflection

### Adjustment Process
1. Director provides final music file (MP3 or WAV)
2. Timeline is measured against actual music duration
3. Shots are scaled/adjusted proportionally to music
4. New MASTER_TIMELINE v1.1 created with precise timings
5. All Scene Packages updated with adjusted shot durations

## Practical Usage for Shot Generation

**For Prompt Engineering:**

When creating SHOT_PROMPT_### for any shot:
1. Reference this MASTER_TIMELINE
2. Locate shot timecode range
3. Note music character/section from "Music Sync Notes"
4. Include music description in Image Prompt ("contemplative section of score," "peak dramatic moment musically," etc.)
5. Ensure Video Prompt motion aligns with music tempo/character

**Example for SHOT_003_C (1:12-1:16, 4 sec):**
```
SHOT_003_C timing: 1:12-1:16 (4 seconds)
Music Sync: Music reaches crescendo; "musical punctuation" for shock moment
Action: Eyes widening; moment of comprehension
Prompt Direction: Eyes must widen in first 1-2 seconds, hold for 2 seconds
```
