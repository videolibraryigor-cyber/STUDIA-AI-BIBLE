## Overview

**MASTER_SHOT_LIST is the complete inventory of every shot in the NICODEMUS film.** It serves as:
- Blueprint for all production work
- Reference for music-to-visual timing (see MASTER_TIMELINE.md)
- Allocation table for SHOT_ID_SYSTEM assignment
- Asset usage matrix (which shots use which characters, locations, props)

**Format:** Organized by dramatic beat (Act) and scene sequence, with shot descriptions tied to PROJECT_BIBLE.md dramatic route.

---

## Dramatic Route Reminder

**Source:** [FILM_BLUEPRINT.md](../../FILM_BLUEPRINT.md) · [01_PRODUCTION_BOOK/PROJECT_BIBLE.md](01_PRODUCTION_BOOK/PROJECT_BIBLE.md)

```
Order → Routine → Confidence → Curiosity → Wonder → Inner Conflict → Fear → Searching → Understanding → Faith → Peace
```

---

## Film Structure Overview

**Blueprint structure:** Opening → Discovery → Flashbacks → Return to Present → Ending

| Act | Dramatic Beat | Est. Duration | Scene Count | Avg Shots/Scene |
|-----|---------------|--------------|-----------|----|
| I | **CURIOSITY** (Setup, discovery begins) | 45-60 sec | 2-3 | 2-3 |
| II | **ASTONISHMENT** (Evidence emerges, wonder grows) | 45-60 sec | 2-3 | 2-3 |
| III | **CONFLICT** (Doubt, questioning intensifies) | 30-45 sec | 1-2 | 2-3 |
| IV | **FEAR & LOSS** (Crisis, internal struggle) | 45-60 sec | 2-3 | 2-3 |
| V | **FAITH & PEACE** (Resolution, acceptance) | 45-60 sec | 2-3 | 2-3 |
| | **TOTAL** | 240-300 sec (4-5 min) | **10-14 scenes** | **2-3** |
