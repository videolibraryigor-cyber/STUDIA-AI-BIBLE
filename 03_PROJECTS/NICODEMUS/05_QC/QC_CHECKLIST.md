# QC CHECKLIST (Контрольный список качества)

## До генерации (Pre-generation)

- [ ] У кадра есть одна ясная сюжетная функция и эмоциональный центр.
- [ ] В Scene Package указаны входное/выходное состояния и связь с соседними кадрами.
- [ ] Выбраны точные locked/approved asset IDs.
- [ ] Камера, объектив, крупность и движение имеют драматургическую причину.
- [ ] Каждый световой источник существует в мире сцены.
- [ ] Промпт не добавляет анахронизмов, фэнтези, лишних эффектов или «голливудской» стилизации.

## Key image (Ключевой кадр)

- [ ] Никодим совпадает с master/face/turnaround reference.
- [ ] Костюм, руки, взгляд, эмоция и поза соответствуют сцене.
- [ ] Библиотека/локация соответствует зафиксированной архитектуре и размещению реквизита.
- [ ] Нет современного, средневекового европейского или фантазийного элемента.
- [ ] Свет, палитра, перспектива и крупность соответствуют Bible.
- [ ] Нет артефактов: лишних пальцев, неестественной кожи, дублей предметов, нечитаемого реквизита.

## Video / edit (Видео / монтаж)

- [ ] Движение начинается и заканчивается в состояниях, заданных пакетом кадра.
- [ ] Нет дрожания личности, одежды, рук, света или предметов между кадрами.
- [ ] Ритм оставляет место тишине; склейка поддерживает, а не заменяет эмоцию.
- [ ] Звук, цвет и VFX не превращают фильм в зрелище.

## Решение (Decision)

`PASS` / `PASS WITH NOTES` / `FAIL — REGENERATE` / `DECISION REQUIRED`.
