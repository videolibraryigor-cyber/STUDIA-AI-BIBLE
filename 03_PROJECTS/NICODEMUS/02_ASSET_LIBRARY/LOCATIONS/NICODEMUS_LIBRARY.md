# NICODEMUS LIBRARY — LOCATION ASSET (Ассет локации)

**ID:** `LOC_NICODEMUS_LIBRARY`  
**Status:** `APPROVED SOURCE REFERENCE`

Частная библиотека состоятельного учителя Закона в Иерусалиме I века: толстые известняковые стены, низкий потолок с тёмными кедровыми балками, одно высокое окно, тяжёлый кедровый письменный стол, простые полки со свитками и глиняными сосудами, одна деревянная скамья/стул, бронзовая масляная лампа, свеча, ниша в стене. Пол из потёртого известняка. Никакой роскоши или декоративного «библейского» китча.

Локация — эмоциональный центр фильма: отсюда начинаются и куда возвращаются воспоминания. Поверхности прожиты, естественно изношены; свет взаимодействует с пылью и дымом без эффектности.
